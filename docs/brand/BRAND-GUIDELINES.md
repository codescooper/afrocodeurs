# Charte graphique AfroCodeurs — v1

> **Statut :** système de marque de référence pour le produit, la communication et les événements.
>
> **Signature :** **Des problèmes aux solutions, ensemble.**
>
> **Principe culturel :** **Build Before Consume.**

## 1. Idée de marque

AfroCodeurs est une communauté panafricaine de bâtisseurs. La marque doit exprimer simultanément :

- **Afrique contemporaine**, sans folklore décoratif gratuit ;
- **construction**, contribution, mouvement et transmission ;
- **technologie accessible**, sérieuse mais non froide ;
- **collectif**, diversité de profils et de pays ;
- **impact concret**, avec les problèmes réels comme point de départ.

### Traits de personnalité

**Directe · énergique · utile · ouverte · fière · collaborative · moderne.**

La marque évite les codes visuels “ONG institutionnelle”, les clichés ethniques génériques et l’esthétique cyberpunk trop abstraite.

## 4. Typographie

La marque doit fonctionner sans dépendre d’une police propriétaire.

### Display
**Geist Sans / Inter / system-ui** en graisse **700–900**.

Usage : titres, chiffres, slogans, affiches, couvertures.

### Texte
**Geist Sans / Inter / system-ui** en graisse **400–600**.

### Code / accent technique
**Geist Mono / JetBrains Mono / monospace**.

Usage : snippets, tags, numéros d’édition, coordonnées techniques, micro-labels.

### Règles

- Titres : courts, très lisibles, avec peu de niveaux hiérarchiques.
- Éviter les capitales intégrales sur de longs titres.
- Les labels peuvent être en capitales avec tracking généreux.
- Une affiche doit rester compréhensible en miniature mobile.

## 5. Logo et symbole

### État actuel

Le repo utilise actuellement une icône provisoire : **A noir sur carré or arrondi**.

Cette icône reste acceptable comme **favicon/app icon transitoire**, mais ne doit pas être considérée comme le logo final institutionnel.

### Système à prévoir

1. **Wordmark AfroCodeurs**
2. **Symbole compact**
3. **Lockup horizontal**
4. **Lockup vertical**
5. **Version monochrome noire**
6. **Version monochrome blanche**
7. **Version or/noir**

### Zone de protection

Autour du logo : au minimum la hauteur du “A” ou du symbole principal.

### Interdits

- déformer ;
- ajouter ombres/glows décoratifs ;
- recolorer librement ;
- poser sur une image sans contraste ;
- intégrer un drapeau national dans le logo mère ;
- ajouter un motif africain décoratif derrière le logo en permanence.

## 6. Langage graphique

### Principe central : **Signal + Structure + Humain**

Chaque visuel AfroCodeurs combine idéalement :

1. **Signal** — un élément or immédiatement identifiable ;
2. **Structure** — grilles, blocs, lignes, tags, repères inspirés des interfaces et du code ;
3. **Humain** — personne, voix, citation, communauté, contexte réel.

### Formes

- rectangles et cartes aux angles légèrement arrondis ;
- bandes franches ;
- traits fins ;
- points/nœuds reliés pour évoquer réseau et collaboration ;
- grille modulaire ;
- fenêtres ou cadres inspirés d’interfaces, sans simuler un faux terminal à chaque création.

### Motifs propriétaires

Motifs possibles, utilisés avec parcimonie :

- **Network Grid** : points + connexions ;
- **Problem → Solution** : flèche, transformation, avant/après ;
- **Code Brackets** : `< >`, `{ }`, `/` comme micro-accent ;
- **Continental Nodes** : carte de l’Afrique abstraite constituée de nœuds, uniquement comme motif secondaire.

## 7. Photographie

### Direction

Montrer des développeurs, designers, étudiants, makers et entrepreneurs africains dans des contextes crédibles :

- coworking ;
- école/université ;
- atelier ;
- conférence ;
- domicile ;
- café ;
- fablab ;
- environnement professionnel réel.

### Traitement

- contraste naturel ;
- peau fidèle ;
- lumière chaude/neutre ;
- cadrages proches et vivants ;
- éviter les banques d’images trop corporate ;
- préférer l’action à la pose.

### Surimpression

L’or peut servir de bande, tag ou ligne. Éviter les filtres jaunes couvrant entièrement les visages.

---

## 8. Illustration

Style recommandé : **afropunk technologique éditorial**, géométrique, contrasté, contemporain.

Éviter :

- clichés “tribaux” génériques ;
- motifs traditionnels utilisés sans contexte ;
- Afrique réduite à une silhouette de continent ;
- excès de néons futuristes.

---

## 9. Iconographie

- traits simples ;
- cohérence de largeur ;
- angles doux ;
- pictos compréhensibles sans légende ;
- Lucide est la base UI actuelle.

Les pictos de programme peuvent recevoir un conteneur or/noir distinctif, mais gardent la même famille.

4. intervenant ou bénéfice

## 11. Ton rédactionnel

### On parle comme une communauté de bâtisseurs

Préférer :

- “Construisons…”
- “Viens apprendre…”
- “Partage ce que tu sais.”
- “Quel problème veux-tu résoudre ?”
- “Ton premier commit compte.”

Éviter :

- jargon corporate ;
- promesses creuses ;
- ton paternaliste ;
- formulations trop institutionnelles.

### Langues

Le français et l’anglais peuvent coexister. Les langues africaines sont encouragées selon le contexte, sans folklorisation.

## 12. Déclinaison — AfroCodeurs Webinars

### Nom
**AfroCodeurs Webinars**

### Rôle
Série éducative et communautaire : expertise pratique, retours d’expérience, régulation, produit, carrière, IA, cybersécurité, open source, etc.

### Signature visuelle

Le webinar conserve le noir/or AfroCodeurs mais ajoute un code graphique propre :

- label fixe **WEBINAR** ou **WEBINAR #XX** en mono ;
- grand titre éditorial ;
- portrait intervenant ou illustration sujet ;
- barre latérale / coin or propriétaire ;
- repère vert uniquement pour “LIVE”, “INSCRIPTIONS OUVERTES” ou état actif.

### Template principal — 1080 × 1350

Ordre :
1. wordmark AfroCodeurs en haut ;
2. tag “WEBINAR #XX” ;
3. titre sur 2–4 lignes ;
4. portrait ou visuel sujet ;
5. nom + fonction intervenant ;
6. date / heure / fuseau ;
7. CTA court ;
8. afrocodeurs.org.

### Formats obligatoires

| Support | Taille |
|---|---:|
| Instagram / LinkedIn portrait | 1080×1350 |
| Instagram carré | 1080×1080 |
| Story / WhatsApp Status | 1080×1920 |
| LinkedIn/X paysage | 1200×675 |
| YouTube thumbnail | 1280×720 |
| Bannière site | 1600×900 |
| Carte événement | ratio 16:9 |

### États de campagne

Le même système doit couvrir :

- **Annonce**
- **Save the date**
- **Speaker reveal**
- **J-7 / J-3 / Demain**
- **Aujourd’hui**
- **Nous sommes en direct**
- **Replay disponible**
- **Citation / extrait**
- **Merci / chiffres clés**

## 14. Accessibilité

- contraste WCAG AA minimum pour le texte ;
- ne jamais coder une information uniquement par couleur ;
- texte essentiel lisible sur mobile ;
- sous-titres obligatoires pour les vidéos publiées ;
- alt text pour les contenus éditoriaux.

---

## 15. Gouvernance

Toute nouvelle déclinaison doit répondre à trois questions :

1. Reconnaît-on AfroCodeurs sans lire le logo ?
2. Le message reste-t-il lisible sur un écran mobile ?
3. La création peut-elle rejoindre le système existant sans inventer une nouvelle identité ?

Si la réponse est non, la création doit être revue.
