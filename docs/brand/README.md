## Règle de gouvernance

Les documents présents ici sont versionnés avec le produit. Une création récurrente validée doit revenir dans ce Brand Hub sous forme de règle, template, composant ou token.

## Export / partage

Les fichiers Markdown sont la source versionnée. Pour communiquer avec un prestataire, exporter la version courante en PDF ou partager le lien GitHub correspondant à la branche/tag validé.

**Ne jamais transmettre une ancienne copie locale de la charte sans numéro de version.**
